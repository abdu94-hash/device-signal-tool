# Toolkit

The 24 editable toolkit files from *Signal Management in Medical Device Vigilance* (Dr. Hafez Selim, MD, PhD; Selim Medical Press), plus `Device_Signal_Toolkit.zip` containing all of them.

See **[INDEX.md](INDEX.md)** for the table of tool IDs, file names, chapters and purposes.

- `T-06`, `T-07` and `T-08` are spreadsheets with live formulas.
- The other 21 files are Word templates.

These are educational templates. Adapt them to your quality system; they are not regulatory requirements. All example data are fictional composites from the book's case dossiers.
